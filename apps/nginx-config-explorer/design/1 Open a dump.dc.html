Get the file

Run one of these where nginx lives. It prints the test result and then every config file it loaded.

$ sudo nginx -T > nginx-full.txt
$ docker exec web nginx -T > nginx-full.txt
$ kubectl exec deploy/web -- nginx -T > nginx-full.txt
