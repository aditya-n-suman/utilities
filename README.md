# utilities

A collection of small, self-contained utilities. Web apps live under `apps/` and browser extensions under `extensions/`, each with its own README.

| App | What it does |
|---|---|
| [`apps/spotify-to-youtube`](apps/spotify-to-youtube) | Converts a public Spotify playlist into a YouTube playlist (temporary link or saved to your account). Status and next steps: [STATUS.md](apps/spotify-to-youtube/STATUS.md) |
| [`apps/nginx-config-explorer`](apps/nginx-config-explorer) | Browse `nginx -T` output like a JSON viewer: fold blocks, follow includes in place, search. Runs fully in the browser. |

| Extension | What it does |
|---|---|
| [`extensions/playlist-bridge`](extensions/playlist-bridge) | Browser extension (Chrome + Firefox) version of the converter that runs entirely in the browser, with no backend and no quotas. Status: [STATUS.md](extensions/playlist-bridge/STATUS.md) |
