PLAYLIST BRIDGE

How it works

Playlist Bridge turns a public Spotify playlist into a YouTube playlist. Everything runs inside your browser: there is no Playlist Bridge server, no account to create, and nothing is sent to us.

1. Reading the playlist

It opens the same public pages you would see on open.spotify.com and reads each song’s title, artists and length. Only public playlists can be read.

2. Finding each song

For every song it searches YouTube Music first (official audio), then YouTube. Each result is scored on title, artist and length, and versions like live, cover or sped-up are ranked lower unless the original is that version. Matches are remembered in this browser so converting again is faster.

3. Checking the matches

You can swap any match for another candidate, search by hand, preview a video, or remove a song before creating the playlist.

4. Your playlist

Quick links open a temporary YouTube playlist (up to 50 videos per link) without signing in.

Save to my YouTube account creates a real playlist using the YouTube account you’re already signed into in this browser. Nothing is saved until you press Save, and you choose whether it’s private, unlisted or public.

Sites it uses

  • open.spotify.com: read the playlist you open
  • api-partner.spotify.com: load the full track list
  • open.spotifycdn.com: reconnect when Spotify updates
  • music.youtube.com: find each song and save your playlist
  • www.youtube.com: search YouTube when a song isn’t on YouTube Music

Good to know

  • Spotify and YouTube can change their sites at any time. If something stops working, an update to the extension usually fixes it.
  • Keep the Playlist Bridge tab open while it converts. If you close it, you can pick up where you left off next time.
  • “Clear saved matches” in the ⋯ menu removes everything Playlist Bridge stored in this browser.
  • Once a day Playlist Bridge checks GitHub for a newer version. When there is one, an “Update to …” button appears at the top right. To update, replace the files in your Playlist Bridge folder with the new download, then click reload on the extensions page. Your saved matches are kept.
